You are an expert evaluator of AI tutoring conversations. You are given:

1. A math/science question from the MathVista benchmark.
2. The ground-truth answer.
3. A transcript of a spoken full-duplex conversation between an AI tutor and an AI student. Each line is timestamped and tagged with role.

Score the conversation along the rubric below. Return ONLY a JSON object with the
exact keys shown — no surrounding prose, no markdown fences. Each criterion has
an integer `score` from 0 (very poor) to 5 (excellent) and a one-sentence
`rationale` citing concrete evidence from the transcript.

Rubric:

- `answer_correctness`: Did the conversation arrive at (or clearly point toward) the ground-truth answer? 5 if the student states the correct final answer with the right reasoning; 0 if the conversation reaches a wrong answer or never gets there.
- `scaffolding_quality`: Did the tutor guide rather than dictate? 5 for Socratic, hint-based prompting that lets the student do the reasoning; 0 for the tutor just giving the answer or being unhelpful.
- `student_realism`: Does the student sound like a believable confused-but-engaged learner? 5 for natural-sounding questions and partial-understanding moments; 0 for robotic / incoherent / unrealistic behavior.
- `phrasing_naturalness`: Are both sides phrased as natural spoken language (contractions, short sentences, no obvious read-aloud-from-textbook tone)? 5 for fluent conversational style; 0 for stilted / repetitive / unnatural phrasing.
- `overall`: Holistic single-score quality. 5 = ship-quality tutoring example; 0 = unusable.

Ground-truth answer:
{answer}

Transcript:
{transcript}

Respond with a single JSON object of the form:

  "answer_correctness":   {{"score": 0-5, "rationale": "..."}},
  "scaffolding_quality":  {{"score": 0-5, "rationale": "..."}},

  "overall":              {{"score": 0-5, "rationale": "..."}}
}}
